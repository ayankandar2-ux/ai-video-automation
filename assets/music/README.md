# Music

Drop royalty-free `.mp3` or `.wav` files here. One is picked at random for each
generated video.

Free sources to pull tracks from:
- YouTube Audio Library (studio.youtube.com → Audio Library) — free, no attribution needed for most tracks
- Pixabay Music (pixabay.com/music) — free, no attribution required
- Free Music Archive (freemusicarchive.org) — check each track's license

This folder is empty by default — the pipeline falls back to silent video if
no tracks are present, so add at least a few before your first real run.
